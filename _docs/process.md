# Development Process

- Work through `backlog.md` one task at a time unless explicitly instructed otherwise.
- Before starting a task, read its Goal, Acceptance Criteria, Out of Scope, and Dependencies.
- During implementation, run the relevant tests for changed behavior.
- Before declaring a task complete, run the full test suite and check every acceptance criterion.
- If implementation requires a new product decision or a change to the frozen specification, stop and ask instead of guessing.
- After finishing a task, report the files changed, acceptance criteria satisfied, tests run and their results, and any unresolved issues.
